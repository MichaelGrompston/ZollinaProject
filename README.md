# ZOLLINA — лендинг умного белья

Адаптивный одностраничный сайт для концепта ZOLLINA — умного впитывающего белья со встроенным экраном уровня наполнения. Проект включает основной лендинг и демонстрационный личный кабинет.

## Страницы

- `zollina-improved.html` — главная страница: описание продукта, преимущества, интерактивная демонстрация датчика, тарифы и форма заявки.
- `account.html` — личный кабинет: форма входа и модальное окно регистрации.

## Возможности

- Адаптивная вёрстка для десктопов и мобильных устройств.
- Тёмный интерфейс в едином фиолетово-бирюзовом стиле.
- Анимированный фон, световая волна и плавная анимация продукта.
- Детализированная встроенная SVG-иллюстрация изделия с экраном сенсора.
- Интерактивный индикатор уровня наполнения.
- Демонстрационные формы входа, регистрации и заявки.
- Поддержка `prefers-reduced-motion` для уменьшения анимаций по системной настройке пользователя.

## Технологии

- HTML5
- CSS3: Flexbox, Grid, media queries, custom properties, keyframes
- Inline SVG
- Vanilla JavaScript
- Google Fonts: Unbounded и Inter

## Запуск

Проект не требует сборки или установки зависимостей. Откройте `zollina-improved.html` в браузере.

```bash
git clone https://github.com/MichaelGrompston/ZollinaProject.git
cd ZollinaProject
```

## Примечание

Все формы в проекте демонстрационные: они не передают данные на сервер. Для реальной авторизации, регистрации и обработки заявок необходимо подключить серверную часть.
